When autonomous coding assistants like Claude Desktop and Cursor are instructed to "search the web for the best Python library to do X", they encounter a dangerous hazard: **SEO spam and synthetic AI slop**.

Blog posts generated by bots routinely recommend abandoned, insecure, or hallucinated packages with fabricated benchmark claims.

If your agent blindly ingests those claims, it writes broken code or introduces critical supply chain vulnerabilities.

---

## Installing FastMCP 2.0 in 60 Seconds

Credence exposes high-performance FastMCP 2.0 tools over standard I/O and SSE transports.

Add Credence to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "credence": {
      "command": "credence",
      "args": ["serve", "--transport", "stdio"]
    }
  }
}
```

## How It Works in Live Workflows

1. **Before Ingestion**: When an agent finds a technical tutorial or benchmark page, it invokes `credence_check_url`.
2. **Grounding Verification**: Credence audits the page for anonymous claims, unverified benchmarks, and deceptive patterns, returning an immutable score.
3. **Prompt Injection Boundary (Invariant 30)**: External prose text is wrapped in `<untrusted_source_text>` blocks, ensuring malicious website text cannot issue hidden instructions to your model.
4. **Confident Synthesis**: The AI agent synthesizes its advice knowing the source material is grounded and validated.
